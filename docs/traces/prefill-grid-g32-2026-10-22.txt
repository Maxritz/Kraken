# 4. MMQ cannot be the exact rung -- decided, not deferred. gemm_mmq.hpp's

#    byte-identical (kraken-bench --bitexact: 0 differing, incl. G=32).
#    Q5_K/Q6_K under KRK_HAS_DOT2 dot in int-code domain (dot_chunk_q6k/q5k
#    via d_dot2_pk), so any LDS-f16 staging must exclude them -- another
#    reason the dequant-once tile died and the grid decodes redundantly.
